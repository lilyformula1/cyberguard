Features

PE Analysis

Architecture, entry point, image base, sections, entropy per section.

API Detection

Identifies suspicious Windows APIs like VirtualAlloc, CreateRemoteThread, and debugger checks.

String Scanner

Extracts printable strings and flags indicators: URLs, cmd.exe, wscript, registry paths, and more.

Entropy Analysis

Calculates section entropy. Flags sections with entropy ≥ 7.0 as potential packing/encryption.

Hash Analysis

Generates MD5, SHA1, and SHA256 hashes for file identification and threat intelligence matching.

Risk Engine

Heuristic scoring (0–100) with LOW/MEDIUM/HIGH classification. Aggregates indicators for rapid triage.
